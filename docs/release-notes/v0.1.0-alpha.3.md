# NEC Workbench v0.1.0 Alpha 3

The third public alpha of NEC Workbench, a cross-platform desktop application for
creating, analyzing, visualizing, and optimizing NEC antenna models.

Alpha 3 brings everything into one main window and works out of the box: it now comes
with the nec2c solver and the example models. See the
[User Guide](https://github.com/fizhoo/NEC-Workbench/blob/v0.1.0-alpha.3/docs/user-guide.md)
for the full tour.

## One main window

- The Home control panel and the separate work and result windows are replaced by one
  resizable main window, laid out like an IDE.
- **Model tree** on the left, with a row for each wire, source, load, network and setup
  item; the **card tables** below it are where you edit wires, sources, loads,
  transmission lines and networks.
- **Variables** under the tree, each with a live slider: drag it and the antenna
  follows; let go and the deck changes once, as one undoable step.
- **Results column** on the right: the key numbers at the selected frequency, with live
  thumbnails of SWR, impedance, patterns and currents. Click one to open the full view.
- **Center views** take turns: the geometry editor, the NEC Deck, each full result
  view, and the Average Gain Test and Segmentation Convergence studies.
- **Bottom panel** for Problems, the Run log, Runs and Raw output.
- **Optimizer** in its own window: it opens beside the main window, keeps running when
  you close it, and closes with the main window.

## Works out of the box

- **nec2c 1.3.3 is included** in both the Windows ZIP and the Linux AppImage, so there is
  nothing to install or configure. The engine list shows **nec2c (bundled)**, the Run log
  starts with the engine, its version and its path, and each run records the engine
  version. You can still pick OpenNEC, 4nec2 NEC2dXS or your own nec2c under
  **Configure…**.
- **Examples are included**: **Open Example…** opens the shipped models.
- **Reopen the last model** at launch (File → Reopen Last Model at Startup; hold Shift to
  skip it once). The start panel lists recent models; `Ctrl+Shift+O` opens Open Recent.

## Modeling

- **Make Variable…**: right-click a field in the Wires table or the wire form to turn
  it into an `SY` variable.
- **Symbols in every card table**: type a variable or an expression into any number
  field, including tags, segment numbers and counts, with completion for known names.
  A new name asks for its value and adds the `SY` card.
- **Live one-frequency solve**: with **Live** on, each committed variable value is solved
  at the selected frequency and the key numbers and thumbnails update at once. Your deck
  and the run history are untouched; **F5** still runs the whole sweep.
- **Undo, Redo, Revert to Saved and Reset**: Reset puts every variable back to its value
  when the model was opened.
- Wires are edited in the deck's own units. New EX, LD, TL and NT cards go before FR
  and RP.
- 4nec2-style `'` comments are read, and sources can be placed by percentage along a wire.

## Geometry

- **Currents coloured on the wires** in the 2D and 3D geometry views and on the 3D
  pattern.
- The big 2D view opens on the antenna's **widest plane** (Top, Front or Side).
- Wire, source and load **labels** stay inside each 2D view, beside their wire, clear of
  the markers and of each other.
- Top, Front, Side, 3D, Fit and Currents are in the view's title line. The views stay
  fitted as the window settles until you zoom, pan or orbit.
- The 3D pattern is a shaded, lit surface, fitted to its view and sorted in depth with
  the antenna.

## Notable fixes

- Every gain, peak, F/B and F/R figure says which direction (El/Az) it refers to; 2D
  patterns are drawn the way EZNEC draws them (Az 0° on the right, elevation cuts over
  ground as the upper half).
- F/R treats only directions more than 90° from forward as rear, so the zenith no longer
  counts. The optimizer uses the same rule as the pattern views.
- SWR is shown against its Z0 everywhere, and a Z0-only change recomputes SWR without
  a re-run.
- New NT cards no longer cut their wires (they start as a 50 Ω connection), and a warning
  flags NT ports that carry no current.
- Automatic Segmentation no longer overwrites symbolic fields; it skips such wires and
  says why.
- The optimizer no longer treats whole-number variables, such as segment counts, as
  continuous.
- Currents and wire selection work on decks where several wires share a tag, or use tag 0.

## Installation

### Windows

Download and extract `NEC-Workbench-Windows-x64.zip`, then run `nec-workbench.exe`.
Keep the extracted files together: the DLLs and folders beside the executable are
needed, nec2c is in `solvers/`, and the examples are in `examples/`.

### Linux

Download `NEC-Workbench-Linux-x86_64.AppImage`, make it executable and run it:

```sh
chmod +x NEC-Workbench-Linux-x86_64.AppImage
./NEC-Workbench-Linux-x86_64.AppImage
```

If it does not start because FUSE is unavailable, run it with
`--appimage-extract-and-run`.

## Alpha Status

This is an early testing release. Please expect interface changes and report
reproducible problems.

Known limitations:

- Packages are not digitally signed. Windows SmartScreen may show "Windows protected your
  PC"; choose **More info → Run anyway**.
- The Linux AppImage is built on Ubuntu 22.04 and needs a distribution of similar age or
  newer.
- On Windows, **Stop** takes about 2 seconds to end a run.
- The Currents view itself is 2D; the 3D views colour wires by current.
- With several sources, "vs. feed" phase is measured against the first source NEC reports.

When reporting an issue, please include your operating system, the engine and version
(the first line of the Run log), the NEC deck, the relevant Run log or output, and the
steps to reproduce it.
